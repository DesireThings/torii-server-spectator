# Torii Server Spectator [![dev chat](https://discordapp.com/api/guilds/188630481301012481/widget.png?style=shield)](https://discord.gg/zeuKQquCSE)

A server handling incoming and outgoing spectator data, multiplayer rooms, and matchmaking for [Torii](https://github.com/ShikkesoraSIM/torii-osu), forked from [osu-server-spectator](https://github.com/ppy/osu-server-spectator).

Interoperates with `torii-server` ([g0v0-server](https://github.com/ShikkesoraSIM/g0v0-server)) over an internal network.

# Testing & Deployment

To deploy this service alongside the Torii server stack, refer to the docker setup in `g0v0-server`.

## Environment variables

| Envvar name                          | Description                                                                                                                                                                                                                                    | Default value                   |
|:-------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------|
| `SAVE_REPLAYS`                       | Whether to save received replay frames from clients to replay files. `1` to enable, any other value to disable.                                                                                                                                | `""` (disabled)                 |
| `REPLAY_UPLOAD_THREADS`              | Number of threads to use when uploading complete replays. Must be positive number.                                                                                                                                                             | `1`                             |
| `REPLAYS_PATH`                       | Local path to store complete replay files (`.osr`) to. Only used if [`FileScoreStorage`](https://github.com/ShikkesoraSIM/torii-server-spectator/blob/master/osu.Server.Spectator/Storage/FileScoreStorage.cs) is active.                     | `./replays/`                    |
| `S3_KEY`                             | An access key ID to use for uploading replays to [AWS S3](https://aws.amazon.com/s3/). Only used if [`S3ScoreStorage`](https://github.com/ShikkesoraSIM/torii-server-spectator/blob/master/osu.Server.Spectator/Storage/S3ScoreStorage.cs) is active.         | `""`                            |
| `S3_SECRET`                          | The secret access key to use for uploading replays to [AWS S3](https://aws.amazon.com/s3/). Only used if [`S3ScoreStorage`](https://github.com/ShikkesoraSIM/torii-server-spectator/blob/master/osu.Server.Spectator/Storage/S3ScoreStorage.cs) is active.    | `""`                            |
| `REPLAYS_BUCKET`                     | The name of the [AWS S3](https://aws.amazon.com/s3/) bucket to upload replays to. Only used if [`S3ScoreStorage`](https://github.com/ShikkesoraSIM/torii-server-spectator/blob/master/osu.Server.Spectator/Storage/S3ScoreStorage.cs) is active.              | `""`                            |
| `TRACK_BUILD_USER_COUNTS`            | Whether to track how many users are on a particular build of the game and report that information to the database at `DB_{HOST,PORT}`. `1` to enable, any other value to disable.                                                              | `""` (disabled)                 |
| `CLIENT_CHECK_VERSION`               | Whether to check whether users connecting to the server are on a build of the game that supports online play.                                                                                                                                  | `""` (disabled)                 |
| `CLIENT_CHECK_VERSION_EXEMPT_GROUPS` | Comma-delimited list of user group IDs. Users in this group will not have their client versions checked even if `CLIENT_CHECK_VERSION` is enabled.                                                                                             | "" (empty set)                  |
| `SERVER_PORT`                        | Which port the server should listen on for incoming connections.                                                                                                                                                                               | `80`                            |
| `REDIS_HOST`                         | Connection string to Redis instance.                                                                                                                                                                                                           | `localhost`                     |
| `DD_AGENT_HOST`                      | Hostname under which Datadog agent host can be found.                                                                                                                                                                                          | `localhost`                     |
| `DB_HOST`                            | Hostname under which MySQL instance can be found.                                                                                                                                                                                              | `localhost`                     |
| `DB_PORT`                            | Port under which MySQL instance can be found.                                                                                                                                                                                                  | `3306`                          |
| `DB_USER`                            | Username to use when logging into MySQL instance.                                                                                                                                                                                              | `osuweb`                        |
| `SENTRY_DSN`                         | A valid Sentry DSN to use for logging application events.                                                                                                                                                                                      | `null` (required in production) |
| `SHARED_INTEROP_DOMAIN`              | The root URL of the web / API instance to which shared interop calls should be submitted.                                                                                                                                                      | `http://localhost:80`           |
| `SHARED_INTEROP_SECRET`              | The shared interop secret matching `torii-server` (`g0v0-server`).                                                                                                                                                                              | `null` (required)               |
| `BANCHO_BOT_USER_ID`                 | Bancho bot user ID.                                                                                                                                                                                                                            | 3                               |
| `MATCHMAKING_ROOM_ROUNDS`            | The number of rounds in a matchmaking room.                                                                                                                                                                                                    | 5                               |
| `MATCHMAKING_HEAD_TO_HEAD_IS_BESTOF` | Whether to treat head-to-head matches (1v1) as best-of matches that end early when score is no longer attainable.                                                                                                                              | true                            |
| `MATCHMAKING_ALLOW_SKIP`             | Whether users are allowed to skip matchmaking stages.                                                                                                                                                                                          | false                           | 
| `MATCHMAKING_LOBBY_UPDATE_RATE`      | The rate (in seconds) at which to update the matchmaking lobby                                                                                                                                                                                 | 5                               |
| `MATCHMAKING_QUEUE_UPDATE_RATE`      | The rate (in seconds) at which to update the matchmaking queues                                                                                                                                                                                | 1                               |
| `MATCHMAKING_QUEUE_BAN_DURATION`     | The duration (in seconds) for which players are temporarily banned from the matchmaking queue after declining an invitation.                                                                                                                   | 60                              |
| `MATCHMAKING_POOL_SIZE`              | The number of beatmaps per matchmaking room.                                                                                                                                                                                                   | 50                              |
